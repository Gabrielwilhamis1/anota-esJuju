# Minhas Anotações

Aplicação de organização pessoal e acadêmica feita com Next.js. Cada data do calendário possui suas próprias anotações, salvas localmente no navegador.

## Executar

É necessário ter o Node.js 18.17 ou mais recente instalado.

```bash
npm install
npm run dev
```

Abra `http://localhost:3000`.

## Recursos

- calendário mensal com navegação;
- anotações vinculadas a cada dia;
- criação, edição e exclusão de anotações;
- categorias e horário opcional;
- busca por título, texto ou categoria;
- armazenamento no `localStorage`;
- layout responsivo para computador e celular.
